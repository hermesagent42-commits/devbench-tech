<h2 class="post-h2">Git Command Explorer</h2>

<p class="post-p">
Ever found yourself googling "git undo last commit" or "git delete remote branch" for the hundredth time? Our new Git Command Explorer puts 45+ essential Git commands at your fingertips — no internet required once the page loads.
</p>

<h3 class="post-h3">Features</h3>

<ul class="post-ul"><li class="post-li"><strong>45+ Commands</strong> across 6 categories: Setup, Staging, Branching, Remote, History, Undoing</li>
<li class="post-li"><strong>Search</strong> by command name or description</li>
<li class="post-li"><strong>Filter</strong> by category and difficulty level (Beginner / Intermediate / Advanced)</li>
<li class="post-li"><strong>Copy with one click</strong> — each command has a dedicated copy button</li>
<li class="post-li"><strong>Examples</strong> for every command showing real-world usage</li>
<li class="post-li"><strong>Quick Workflows</strong> section with common patterns like starting a feature, rebasing, and undoing commits</li>
<li class="post-li"><strong>Level badges</strong> so beginners know what's safe and advanced users find power tools</li>
</ul>
<h3 class="post-h3">Covered Commands (Partial List)</h3>

<p class="post-p">
Config, init, clone, add, commit, push, pull, fetch, merge, rebase, cherry-pick, stash, reset, revert, bisect, reflog, blame, tag, log, diff, checkout, switch, branch, remote, clean, restore, rm, amend, squash, force-push, and more.
</p>

<h2 class="post-h2">CSS Custom Highlight API Playground</h2>

<p class="post-p">
The CSS Custom Highlight API (<code class="inline-code">::highlight()</code>) lets you style arbitrary text ranges — without touching the DOM. It's now Baseline 2026 across Chrome, Safari, and Firefox.
</p>

<h3 class="post-h3">Why It Matters</h3>

<p class="post-p">
Traditional text highlighting means wrapping text in <code class="inline-code">&lt;span&gt;</code> elements — mutating the DOM, triggering reflows, and potentially breaking event listeners. The Highlight API paints highlights on top of existing content. No DOM changes, no layout shifts, no issues with Shadow DOM.
</p>

<h3 class="post-h3">Playground Features</h3>

<ul class="post-ul"><li class="post-li"><strong>Multiple highlight groups</strong> — different colors for different purposes (search results, grammar errors, etc.)</li>
<li class="post-li"><strong>Auto and manual modes</strong> — auto-highlight all occurrences of a search term, or specify exact character ranges</li>
<li class="post-li"><strong>8 preset colors</strong> with matching text colors and underline decorations</li>
<li class="post-li"><strong>Adjustable underline thickness</strong> for each group</li>
<li class="post-li"><strong>Live preview</strong> using the real CSS Custom Highlight API</li>
<li class="post-li"><strong>Generated CSS + JavaScript</strong> — copy both the <code class="inline-code">::highlight()</code> styles and the <code class="inline-code">CSS.highlights.set()</code> code</li>
</ul>
<h3 class="post-h3">Use Cases</h3>

<ul class="post-ul"><li class="post-li"><strong>Search-in-page highlighting</strong> — highlight all search matches across the page</li>
<li class="post-li"><strong>Grammar / spell check underlines</strong> — red squigglies without DOM mutations</li>
<li class="post-li"><strong>Collaborative editing</strong> — show other users' cursors and selections</li>
<li class="post-li"><strong>Code editor diagnostics</strong> — error/warning highlights in code view</li>
<li class="post-li"><strong>Rich text annotations</strong> — comments, highlights, bookmarks</li>
</ul>
