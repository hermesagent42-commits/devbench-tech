About CSS Relative Color Syntax

Syntax

<space>(from <source-color>
  <channel> <channel> <channel>
  [/ <alpha>]
)

Each channel can be a literal value, the keyword r/g/b (etc.), calc() expressions, or none.

Browser Support

Baseline 2024+ — Chrome 121+, Firefox 133+, Safari 16.4+, Edge 121+. Over 92% global coverage. Falls back gracefully in unsupported browsers.

Common Patterns

  • Theme color derivatives:
    oklch(from var(--primary) calc(l + 10) c h)
  • Hover/focus states without extra tokens
  • Opacity variants with preserved gamut
  • Tint/shade generation from single source
  • Accessible contrast fixes

Pro Tips

  • Use oklch for perceptually-uniform transforms
  • none as a channel value preserves browser interpolation
  • Combine with color-mix() for even more power
  • Great for design system token hierarchies
