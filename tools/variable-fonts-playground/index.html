About Variable Fonts

Variable fonts (OpenType 1.8+) pack multiple font styles into a single file. One variable font file covers an entire design space instead of loading separate files for each weight, width, or style. Control exact appearance with font-variation-settings in CSS. 93% of browsers support variable fonts globally.
