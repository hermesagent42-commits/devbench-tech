Quick Workflows

🆕 Start a new feature
git checkout -b feature/new-thing# ... make changes ...git add . && git commit -m "feat: new thing"git push -u origin feature/new-thing
🔀 Pull latest & rebase
git checkout maingit pull --rebase origin maingit checkout feature/branchgit rebase main
⏪ Undo last commit (keep changes)
git reset --soft HEAD~1
🧹 Clean merged branches
git branch --merged | grep -v "\\*\\|main" | xargs -n 1 git branch -d
