Generated CSS

/* Apply to each card/item in the feed */.card {  content-visibility: auto;  contain-intrinsic-size: auto 400px;}/* With "auto", the browser automatically: *  - Skips rendering for off-screen elements *  - Preserves layout space via contain-intrinsic-size *  - Renders elements as they scroll into view *  - Result: only ~6/50 cards rendered at a time */

How content-visibility Works

visible (default) — Normal rendering. Every element is painted and laid out, even if off-screen.
auto ✦ Baseline 2026 — Browser skips rendering for elements outside the viewport. When the element scrolls near the viewport, it renders automatically. Use contain-intrinsic-size to reserve space and prevent layout shifts.
hidden — Never rendered (like display: none), but preserves layout space. Useful for hiding sections while keeping page structure.

Performance Impact

On a page with 100+ items, content-visibility: auto can reduce initial layout/paint work by 60-90%. The browser only renders what the user can see — the rest is deferred until scroll.
