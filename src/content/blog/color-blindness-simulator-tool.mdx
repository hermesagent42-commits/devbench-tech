Color is the most abused tool in UI design.

We use red for errors, green for success, blue for links, and orange for warnings — and then we're surprised when 1 in 12 men (and 1 in 200 women) can't tell the difference. Status indicators that rely solely on color. Data visualizations where adjacent segments are identical shades. Error messages that disappear into the background.

Color vision deficiency (CVD) affects over **350 million people worldwide**. That's not a niche edge case — it's roughly the population of the United States. If your app has a million users, statistically ~40,000 of them have some form of CVD.

## Introducing the Color Blindness Simulator

We've added a **Color Blindness Simulator** to DevBench that lets you see your designs the way someone with CVD would see them. It's free, runs entirely in your browser, and requires no sign-up.

### What It Does

The simulator covers all 8 recognized types of color vision deficiency:

| Type | Description | Prevalence |
|------|-------------|------------|
| **Protanopia** | Red-blind — no red cone response | ~1% of males |
| **Protanomaly** | Red-weak — reduced red sensitivity | ~1% of males |
| **Deuteranopia** | Green-blind — no green cone | ~1.5% of males |
| **Deuteranomaly** | Green-weak — reduced green | ~5% of males |
| **Tritanopia** | Blue-blind — no blue cone | ~0.003% |
| **Tritanomaly** | Blue-weak — reduced blue | ~0.01% |
| **Achromatopsia** | Complete color blindness | ~0.003% |
| **Achromatomaly** | Partial achromatopsia | Very rare |

### How to Use It

1. **Upload an image** — a screenshot of your UI, a data visualization, a logo, anything
2. **Select a CVD type** from the sidebar — each one shows its severity and population stats
3. **Toggle compare mode** for a side-by-side original vs. simulated view
4. **Test individual colors** with the color picker to see how specific hex values appear
5. **Check the palette test** — 15 common colors with before/after hex values
6. **Download the simulated image** or **copy the CSS filter** to use in your own tests

### The Technology

The simulator uses the **Machado-Oliveira-Fernandes model** — a physiologically accurate color vision deficiency simulation based on human cone response data. The math translates to SVG `feColorMatrix` filters:

```css
/* Simulate deuteranopia (green-blindness) */
filter: url("data:image/svg+xml,...feColorMatrix type='matrix' values='0.625 0.375 0 0 0  0.7 0.3 0 0 0  0 0.3 0.7 0 0  0 0 0 1 0'...");
```

Everything runs client-side — no data leaves your browser.

## Practical Lessons from Simulating CVD

After running dozens of popular websites through the simulator, here's what we've learned:

### 1. Red/Green Status Indicators Are a Disaster

The most common CVD type (deuteranomaly, affecting 5% of males) makes red and green nearly indistinguishable. If your error and success states use `#ef4444` and `#22c55e` with no icons, a significant portion of your users see the same brownish-yellow for both.

**Fix**: Always pair color with an icon (✓ for success, ✗ for error) or text label. Never rely on color alone.

### 2. Data Visualization Palettes Break Completely

A 5-color chart using red, green, brown, orange, and purple collapses into 2–3 indistinguishable clusters under deuteranopia. Tools like Okabe-Ito or ColorBrewer provide proven CVD-safe palettes.

### 3. Links Without Underlines Disappear

Blue `#3b82f6` looks nearly identical to dark gray `#374151` under protanopia. If your links are styled with `text-decoration: none` and rely on color alone, users with protanopia can't identify them.

**Fix**: Underline links or add a distinct visual indicator like an arrow icon.

### 4. Form Validation States Need More Than Color

A border that changes from gray to red on error — without an error message or icon — is invisible under deuteranopia. The border just stays... gray.

**Fix**: Always display error text alongside color changes. Use `aria-invalid="true"` for screen readers.
