About white-space

  • normal — Sequences of whitespace collapse into one space. Text wraps. Newlines behave like spaces. The browser default.
  • nowrap — Collapses whitespace like normal but never wraps. Overflow hidden unless you add overflow-x: auto or text-overflow: ellipsis.
  • pre — Preserves all whitespace exactly. No wrapping. Behaves like the HTML <pre> element.
  • pre-wrap — Preserves whitespace and newlines but wraps long lines. Great for code blocks that need to fit responsive containers.
  • pre-line — Collapses spaces and tabs but preserves newlines. Text wraps normally. Good for poetry or addresses.
  • break-spaces — Same as pre-wrap but any sequence of spaces can be a line break opportunity. Spaces at the end of a line “hang” visually.

CSS 2.1/3 · All browsers · break-spaces: Chrome 76+, Firefox 69+, Safari 13.1+
