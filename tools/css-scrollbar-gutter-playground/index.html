What does scrollbar-gutter do?

When content overflows, a scrollbar appears — and unless you handle it, the content shifts left by the scrollbar width (usually 15–17px). This causes cumulative layout shift (CLS) — one of Google's Core Web Vitals. scrollbar-gutter: stable reserves scrollbar space even when the scrollbar is hidden, so content never jumps.

Usage Tips

  • ▸Apply to html or body — one rule prevents layout shift site-wide. No per-component CSS needed.
  • ▸Use stable both-edges for centered layouts — when you use margin: 0 auto, the content stays perfectly centered even with a scrollbar.
  • ▸Combine with overflow-y: auto — the gutter only works with scrollable elements. Without overflow, nothing happens.
  • ▸Browser support — Baseline 2024. Works in Chrome 94+, Firefox 97+, Safari 15.4+, Edge 94+. Safe to use everywhere today.
  • ▸Compare to overflow-y: scroll — that forces a visible scrollbar (ugly when not needed). scrollbar-gutter: stable reserves invisible space (cleaner).
