## Why DevBench?

Every developer has a collection of bookmarked tools. JSON formatters, Base64 encoders, regex testers — you use them weekly, but they're scattered across different sites. Most of them have ads, trackers, or require signups.

**DevBench fixes this.**

All tools run client-side in your browser. Your data never leaves your machine. No accounts, no ads, no JavaScript tracking (we do have a privacy-respecting page view counter that we'll explain below).

## What's Available Today

We're launching with four core tools:

- **JSON Formatter** — Pretty-print, minify, and validate JSON with syntax highlighting
- **Base64 Encoder/Decoder** — Quick encode/decode with instant results
- **UUID Generator** — Generate single or batch UUID v4 identifiers
- **Regex Tester** — Test patterns with real-time matching and capture group extraction

## What's Coming

We're actively building:
- **Color Converter** (HEX ↔ RGB ↔ HSL)
- **JWT Debugger** (decode and inspect tokens)
- **Framework Benchmarks** (Next.js vs Nuxt vs SvelteKit and more)
- Regular blog posts on developer topics

## Privacy by Design

No data is sent to any server. Every tool processes your input locally. The only network request is an anonymous page view counter (powered by Supabase) — no cookies, no fingerprinting, no third-party scripts.

## Open Source

DevBench is fully open source. You can inspect the code, suggest features, or contribute at our GitHub repository.
