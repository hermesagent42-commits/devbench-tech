HTMX Attribute Reference

Complete reference for every HTMX attribute — from core requests to advanced swap strategies. Search, filter by category, and copy attributes.

Core Request Attributes

5 attrs
hx-get

GET Request

Issues a GET request to the specified URL.

hx-post

POST Request

Issues a POST request to the specified URL.

hx-put

PUT Request

Issues a PUT request to the specified URL.

hx-patch

PATCH Request

Issues a PATCH request to the specified URL.

hx-delete

DELETE Request

Issues a DELETE request to the specified URL.

Target & Swap

5 attrs
hx-target

Target Element

Specifies which element will be updated with the response.

hx-swap

Swap Strategy

Controls how the response content is swapped into the DOM.

hx-swap-oob

Out-of-Band Swap

Allows response elements to target elements outside the current target.

hx-select

Select Content

Selects a subset of the response to be swapped.

hx-select-oob

Select OOB

Selects elements from the response for out-of-band swaps.

Triggers & Events

2 attrs
hx-trigger

Trigger

Specifies what event triggers the request.

hx-on

Inline Event Handler

Handle any HTMX event inline with scripting expressions.

Request Configuration

7 attrs
hx-params

Request Parameters

Controls which parameters are included with the request.

hx-vals

Additional Values

Adds extra values to request parameters in JSON format.

hx-vars

Dynamic Variables

Declares JavaScript variables available during hx-vals/js evaluation.

hx-include

Include Elements

Includes additional element values in the request.

hx-ext

Extensions

Enables HTMX extensions for this element.

hx-headers

Custom Headers

Adds custom HTTP headers to the request.

hx-encoding

Form Encoding

Controls the encoding type for form submissions.

Loading & Indicators

3 attrs
hx-indicator

Loading Indicator

Shows a loading indicator during the request.

hx-disable

Disable Element

Disables HTMX processing for this element and its children.

hx-disabled-elt

Disabled Element

Adds the disabled attribute to specified elements during requests.

History & Navigation

5 attrs
hx-push-url

Push URL

Pushes a new URL into the browser history.

hx-replace-url

Replace URL

Replaces the current URL in the browser location bar.

hx-boost

Boost Links/Forms

Progressively enhances anchors and forms to use AJAX.

hx-history-elt

History Element

Specifies the element to snapshot for history restoration.

hx-history

History Control

Controls whether an element participates in history snapshots.

Confirmation & Validation

3 attrs
hx-confirm

Confirm Action

Shows a confirm dialog before issuing the request.

hx-prompt

Prompt for Value

Shows a prompt dialog to collect user input.

hx-validate

Validate Form

Forces HTML5 form validation before request.

Swap Fine-Tuning

5 attrs
hx-swap-settle

Settle Delay

Overrides the default settle delay for this element.

hx-swap-transition

Swap Transition

Adds a CSS transition during the swap.

hx-preserve

Preserve Element

Preserves an element across swaps (maintains state).

hx-focus-scroll

Focus/Scroll

Controls focus and scroll after swap.

hx-sync

Synchronize Requests

Synchronizes requests between elements.

Based on the HTMX Reference Documentation. HTMX is a library that gives you access to AJAX, CSS Transitions, WebSockets, and Server Sent Events directly in HTML.
