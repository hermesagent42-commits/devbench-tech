Quick Tips

  • • PostgreSQL: use JSONB for arrays/objects. MySQL: JSON.
  • • Numbers are auto-detected as INTEGER vs DOUBLE based on value type.
  • • Date strings (YYYY-MM-DD) are detected as DATETIME/TIMESTAMP columns.
  • • Boolean values become BOOLEAN (PG), TINYINT(1) (MySQL), or INTEGER (SQLite).
  • • All processing happens in your browser — no data is ever sent anywhere.
