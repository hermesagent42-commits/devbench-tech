Component Definition (JS)
class MyElement extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = `
      <style>
        .wrapper {
  padding: 20px;
  background: #1e293b;
  border-radius: 10px;
  text-align: center;
  border: 1px solid #334155;
}
h2 {
  margin: 0 0 8px;
  font-size: 20px;
  color: #f1f5f9;
}
p {
  margin: 0;
  color: #94a3b8;
  font-size: 14px;
}
      </style>
      <div class="wrapper">
  <h2>Hello <slot>World</slot>!</h2>
  <p>This is a web component.</p>
</div>
    `;
  connectedCallback() {
    const greeting = this.getAttribute('greeting') || 'Hello';
    const theme = this.getAttribute('theme') || 'light';
    this.shadowRoot.querySelector('h2').textContent = greeting + '!';
  }
  
  static get observedAttributes() { return ['greeting', 'theme']; }
  
  attributeChangedCallback(name, oldVal, newVal) {
    if (!this.shadowRoot) return;
    if (name === 'greeting') {
      this.shadowRoot.querySelector('h2').textContent = newVal + '!';
    }
  }
}

customElements.define('my-element', MyElement);
Usage in HTML
<my-element greeting="" theme="">
  <!-- slot content here -->
</my-element>

About Web Components

Shadow DOM

Styles and DOM are fully encapsulated. No CSS leaks in or out. Access elements via this.shadowRoot.

Custom Elements

Define new HTML tags with customElements.define(). Tag names must contain a hyphen.

Lifecycle

connectedCallback — added to DOM. disconnectedCallback — removed. attributeChangedCallback — attr change.
