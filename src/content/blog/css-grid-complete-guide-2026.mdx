CSS Grid Layout is the most important CSS feature of the last decade. It's not just another layout method — it's a complete two-dimensional layout engine that replaced floats, table hacks, and the mental gymnastics of centering. Grid is Baseline across every browser, including IE11 (with `-ms-` prefixes).

This is the guide I wish I had when I started. It covers everything: the mental model, every property, the `fr` unit, `minmax()`, `auto-fill` vs `auto-fit`, subgrid, alignment, and 10 real-world layout patterns you can copy-paste into production.

## The Mental Model: Rows, Columns, and the Grid Container

Think of Grid as a spreadsheet layout engine. You define **rows** and **columns** on a parent, then place **children** into cells:

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}
```

This gives you a **holy grail layout** in three lines of CSS — header, sidebar, main content, sidebar, footer. No flexbox wrappers, no calc(), no JavaScript. Just Grid.

## The Grid Container Properties

These are the properties you set on the **parent** element (`display: grid`):

### `grid-template-columns` and `grid-template-rows`

Define the track sizes. This is where Grid shines — you can mix fixed, flexible, and content-based tracks:

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 2fr 100px;
  /* Fixed, flexible, flexible (2x), fixed */
  
  grid-template-rows: 60px auto 60px;
  /* Fixed header, fluid content, fixed footer */
}
```

### The `fr` Unit — Fractional Magic

`fr` divides the **remaining space** after fixed tracks are accounted for:

```css
grid-template-columns: 1fr 1fr 1fr;    /* Equal thirds */
grid-template-columns: 2fr 1fr 1fr;    /* 50% / 25% / 25% */
grid-template-columns: 300px 1fr 1fr;  /* Fixed sidebar, fluid rest */
```

The `fr` unit competes with `auto` for remaining space. `auto` gives the track the size of its content; `fr` gives it a fraction of free space.

### `repeat()` — Don't Repeat Yourself

```css
grid-template-columns: repeat(12, 1fr);        /* 12 equal columns */
grid-template-columns: repeat(3, 200px 1fr);   /* Pattern repeats: 200px 1fr 200px 1fr 200px 1fr */
```

### `minmax()` — The Game-Changer

`minmax(min, max)` lets a track shrink to a minimum and grow to a maximum:

```css
grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
```

This is the **responsive card grid** pattern. Each column is at least 250px wide and can grow to fill remaining space. When the container is too narrow for another 250px column, a new row wraps. **Zero media queries.**

### `auto-fill` vs `auto-fit` — The Subtle Difference

Both create as many tracks as will fit, but they behave differently when there's extra space:

```css
/* auto-fill: creates empty tracks (they take up space) */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

/* auto-fit: collapses empty tracks (remaining items stretch) */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

**Rule of thumb:** Use `auto-fill` when you want consistent column sizing even with few items. Use `auto-fit` when you want items to stretch and fill the row.

### `gap` (formerly `grid-gap`)

```css
.grid {
  gap: 24px;                      /* Both row and column */
  gap: 24px 16px;                 /* row-gap column-gap */
  row-gap: 24px;
  column-gap: 16px;
}
```

### `grid-template-areas` — The Visual Layout Method

This is the most intuitive way to define layouts. You draw a grid with named areas:

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header  header"
    "sidebar content aside"
    "footer  footer  footer";
  min-height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.aside   { grid-area: aside; }
.footer  { grid-area: footer; }
```

For responsive layouts, redefine areas per breakpoint:

```css
@media (max-width: 768px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "content"
      "sidebar"
      "aside"
      "footer";
  }
}
```

## Grid Item Placement Properties

These go on the **children** of the grid container:

### Line-Based Placement

Grid lines are numbered starting at 1 (and negative numbers count from the end):

```css
.item {
  grid-column: 1 / 3;       /* Start at line 1, end at line 3 (spans 2 columns) */
  grid-column: 1 / -1;      /* Full width */
  grid-row: 2 / 4;          /* Starts at row line 2, ends at line 4 */
}
```

Shorthand:
```css
.item {
  grid-column: 2 / span 3;  /* Start at line 2, span 3 columns */
  grid-row: 1 / span 2;     /* Start at row 1, span 2 rows */
}
```

The ultimate shorthand:
```css
.item {
  grid-area: row-start / col-start / row-end / col-end;
  grid-area: 1 / 2 / 3 / 5;
}
```

### Auto-Placement and `grid-auto-flow`

When items aren't explicitly placed, Grid auto-places them in source order:

```css
.grid {
  grid-auto-flow: row;      /* Default: fill rows first */
  grid-auto-flow: column;   /* Fill columns first */
  grid-auto-flow: dense;    /* Backfill holes (can reorder items) */
}
```

### Implicit Grid: `grid-auto-rows` and `grid-auto-columns`

When you have more items than explicitly defined tracks, Grid creates **implicit tracks**. Control their size:

```css
.grid {
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 200px;       /* All new rows are 200px tall */
  grid-auto-rows: minmax(100px, auto); /* At least 100px, grows with content */
}
```

## Alignment in Grid

Grid has two axes: **block** (rows, vertical) and **inline** (columns, horizontal). Alignment properties target items within their cells.

### Container-Level Alignment

Applied to the grid container, affects all items:

```css
.grid {
  /* Align items within their cells (vertical) */
  align-items: start | end | center | stretch;
  
  /* Align items within their cells (horizontal) */
  justify-items: start | end | center | stretch;
  
  /* Shorthand for both */
  place-items: center;           /* Center both axes */
  place-items: center start;     /* Vertically center, horizontally start */
}
```

### Content-Level Alignment

When the grid is smaller than the container, align the grid itself:

```css
.grid {
  /* Align the entire grid (vertical) */
  align-content: start | end | center | stretch | space-between | space-around | space-evenly;
  
  /* Align the entire grid (horizontal) */
  justify-content: start | end | center | stretch | space-between | space-around | space-evenly;
  
  /* Shorthand */
  place-content: center;
}
```

### Item-Level Alignment

Override container alignment on individual items:

```css
.item {
  align-self: start | end | center | stretch;
  justify-self: start | end | center | stretch;
  place-self: center;
}
```

## Subgrid — Aligning Nested Grids

Subgrid lets a child grid inherit the track sizing of its parent. This solves the problem of aligning content across separate grid items:

```css
.parent {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.child {
  display: grid;
  grid-template-columns: subgrid; /* Inherit parent column tracks */
  grid-column: span 3;            /* Span all parent columns */
}
```

Now the child's items align perfectly with the parent's column tracks — imagine a card with a title, description, and button that all align across cards in a row:

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.card {
  display: grid;
  grid-template-rows: subgrid;
  grid-row: span 3;  /* Header, body, footer — all aligned across cards */
  gap: 0;
}
```

Subgrid is Baseline since mid-2024 across all browsers.

## 10 Production-Ready Grid Patterns

### 1. Responsive Card Grid (No Media Queries)

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}
```

### 2. Holy Grail Layout

```css
.holy-grail {
  display: grid;
  grid-template-columns: 250px 1fr 250px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header  header"
    "nav     main    aside"
    "footer  footer  footer";
  min-height: 100vh;
}
```

### 3. Centered Single Element

```css
.center {
  display: grid;
  place-items: center;
  min-height: 100vh;
}
```

Two properties, perfect centering. No flexbox, no transform tricks, no negative margins.

### 4. Pancake Stack (Header / Content / Footer)

```css
.pancake {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}
```

### 5. Sidebar + Content

```css
.sidebar-layout {
  display: grid;
  grid-template-columns: 280px 1fr;
  min-height: 100vh;
}

@media (max-width: 768px) {
  .sidebar-layout {
    grid-template-columns: 1fr;
    grid-template-rows: auto 1fr;
  }
}
```

### 6. 12-Column Page Layout

```css
.page-grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
}

.full-width  { grid-column: 1 / -1; }
.half        { grid-column: span 6; }
.third       { grid-column: span 4; }
.two-thirds  { grid-column: span 8; }
.quarter     { grid-column: span 3; }
```

### 7. RAM (Repeat, Auto, Minmax) — The Ultimate Pattern

```css
.ram {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 350px), 1fr));
  gap: 24px;
}
```

The `min(100%, 350px)` ensures nothing overflows on tiny screens. This pattern handles **every screen size** with zero media queries.

### 8. Overlapping Elements (No Position Absolute)

```css
.overlap {
  display: grid;
  grid-template-columns: 1fr;
  grid-template-rows: 1fr;
}

.overlap > * {
  grid-area: 1 / 1; /* All children in the same cell */
}

.background { z-index: 0; }
.foreground { z-index: 1; place-self: center; }
```

### 9. Masonry-Like Layout (Rows + Column Span)

```css
.masonry {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  grid-auto-rows: 10px;  /* Small row height for fine control */
  gap: 16px;
}

.masonry > :nth-child(3n+1) { grid-row: span 20; }  /* Tall */
.masonry > :nth-child(3n+2) { grid-row: span 14; }  /* Medium */
.masonry > :nth-child(3n+3) { grid-row: span 17; }  /* Tall */
```

Note: Native CSS `masonry` layout is in development but not yet Baseline. This pattern is the reliable approach.

### 10. Dashboard / Admin Layout

```css
.dashboard {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 56px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar content";
  height: 100vh;
}

.sidebar { grid-area: sidebar; }
.header  { grid-area: header; }
.content {
  grid-area: content;
  overflow: auto;
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 16px;
  padding: 24px;
}
```

## Grid vs Flexbox: When to Use Each

This isn't a competition. Use both. They complement each other perfectly.

| Situation | Use |
|-----------|-----|
| Two-dimensional layout (rows AND columns) | **Grid** |
| One-dimensional layout (row OR column) | **Flexbox** |
| Complex page layouts | **Grid** |
| Component-level alignment | **Flexbox** |
| Equal-width columns with responsive wrapping | **Grid** (`auto-fill`/`auto-fit`) |
| Variable-width items in a row | **Flexbox** (`flex-wrap`) |
| Vertical centering of a single element | Both work — Grid's `place-items: center` is simpler |
| Navigation bars, toolbars, button groups | **Flexbox** |
| Form layouts with aligned labels | **Grid** |
| Intrinsic sizing (sized by content) | **Flexbox** |

**The real answer:** Nest a flexbox component inside a grid layout. Grid handles the macro-layout, Flexbox handles the micro-layout.

```css
.page {
  display: grid;
  grid-template-columns: 250px 1fr;
}

.toolbar {
  display: flex;
  align-items: center;
  gap: 12px;
}
```

## Common Pitfalls

### 1. Forgetting `display: grid` is on the PARENT

Grid properties on the container control children. Children don't become grid containers unless you set `display: grid` on them too.

### 2. `auto` vs `1fr` — Not the Same

```css
grid-template-columns: auto 1fr;
```

`auto` sizes to content. `1fr` takes remaining space. If you want equal columns, use `1fr 1fr`.

### 3. `gap` Applies Between Tracks, Not at Edges

`gap` creates space between grid cells, not around the edges of the grid. Use `padding` on the container for outer spacing.

### 4. `span` Counts Tracks, Not Lines

```css
grid-column: 1 / span 2;  /* Spans 2 columns (lines 1-3) */
grid-row: span 3;         /* Spans 3 rows from auto-placement */
```

### 5. Implicit Grid Surprises

If you define 3 columns but have 4 children, Grid creates an implicit row. Control its size with `grid-auto-rows` or `grid-auto-columns` — otherwise it defaults to `auto`.

### 6. `minmax()` Requires Both Arguments

```css
/* Wrong */
grid-template-columns: repeat(3, minmax(200px)); /* Invalid */

/* Right */
grid-template-columns: repeat(3, minmax(200px, 1fr));
```

### 7. Named Lines and Named Areas Use Different Syntax

```css
/* Named lines */
grid-template-columns: [col-start] 1fr [col-end];

/* Named areas — no brackets, just strings */
grid-template-areas: "header header";
```

## DevTools Debugging

Chrome, Firefox, and Safari all have dedicated Grid inspectors:

- **Chrome/Firefox:** Click the "grid" badge next to a `display: grid` element in the Elements panel. This overlays track lines, gap visualization, and area names.
- **Safari:** The "Grid" checkbox appears in the Elements panel for grid containers.
- **Edge:** Same as Chrome — they share the DevTools engine.

Enable `display line numbers` and `display area names` in the Grid overlay settings for the full picture.

## Key Takeaways

1. **Grid is for two-dimensional layouts.** If you're managing rows AND columns, reach for Grid.
2. **`minmax()` + `auto-fill`/`auto-fit` = responsive without media queries.** This pattern alone eliminates half your breakpoints.
3. **Named grid areas make layouts self-documenting.** `grid-template-areas` is the CSS equivalent of a wireframe.
4. **Subgrid makes nested grids practical.** Cards that align across rows, form fields that share column widths — subgrid solves these.
5. **Grid and Flexbox are complementary.** Use Grid for page-level structure, Flexbox for component-level alignment.
6. **DevTools make Grid visible.** Overlay grid lines and area names during development — it removes all guesswork.

CSS Grid isn't new in 2026 — it's foundational. Every developer should have these patterns internalized. They're the difference between fighting CSS and loving it.
