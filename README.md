# DevBench

> Free developer tools, benchmarks & calculators — all running in your browser.

## Tools

- **JSON Formatter** — Pretty-print, minify, and validate JSON
- **Base64 Encoder/Decoder** — Encode and decode Base64 strings
- **UUID Generator** — Generate v4 UUIDs, single or batch
- **Regex Tester** — Test regular expressions with highlight matching
- **Color Converter** — Convert between HEX, RGB, HSL *(coming soon)*
- **JWT Debugger** — Decode and inspect JWTs *(coming soon)*

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (analytics)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Privacy

All tools process data locally in your browser. No data is sent to any server. Page views are counted anonymously via Supabase with no cookies or fingerprinting.
