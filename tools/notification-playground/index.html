Notification API Facts

  • • Secure Context: Requires HTTPS (or localhost)
  • • Permission: Must be explicitly granted by the user
  • • Tags: Replace earlier notifications with the same tag
  • • Silent: No sound/vibration — requires silent permission grant
  • • Actions: Up to 2 buttons (Chrome/Edge only)
  • • requireInteraction: Keeps notification visible until user dismisses
  • • Service Workers: Enable notifications even when page is closed
