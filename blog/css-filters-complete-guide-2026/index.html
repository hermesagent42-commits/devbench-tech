CSS filter(): The Complete Visual Guide to All 11 Filter Functions

Every CSS filter function explained with visual examples — blur, brightness, contrast, drop-shadow, grayscale, hue-rotate, invert, opacity, saturate, sepia, and the SVG url() filter. Learn how to chain them, animate them, and avoid performance pitfalls in 2026.

Why CSS Filters Matter Now

CSS filters landed as Baseline in 2015 and every browser has supported them for nearly a decade. Yet most developers barely scratch the surface — a little blur() for glassmorphism, maybe grayscale() on hover. The full filter pipeline can replace image editing tools for common tasks, animate smoothly at 60fps, and create effects that used to require Canvas or WebGL.

Here's what you need to know: CSS filters operate on the rendered output of an element and all its descendants. They're applied after layout and painting, composited by the GPU, and — when used correctly — they don't trigger repaints or reflows.

There are eleven filter functions plus one escape hatch (url() for SVG filters). This guide covers all of them with visual examples, performance data, and practical patterns.

The Complete Filter Pipeline

Every filter function accepts a value and returns a modified pixel output. The GPU runs the filter in a single pass, applying each function in order. Chain them with spaces: 

filter: blur(2px) grayscale(0.5) drop-shadow(4px 4px 0 crimson);

The order matters — blur() then grayscale() produces different results than grayscale() then blur().

1. blur() — The Glassmorphism Workhorse

filter: blur(5px);        /* Radius in pixels, 0+ */
filter: blur(1.5rem);     /* Any CSS length — px, rem, em, vw */

What it does: Gaussian blur with the specified standard deviation. The browser computes a convolution kernel — larger values mean wider, softer blur. 

.card-backdrop {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(12px);   /* Blurs content BEHIND */
}

.skeleton-loader {
  filter: blur(4px);              /* Blurs the element ITSELF */
  animation: pulse 1.5s ease-in-out infinite;
}

Key distinction: backdrop-filter: blur() blurs what's behind the element (requires transparency on the element). filter: blur() blurs the element and its children. Never mix them up.

Performance: The most expensive filter. Blur radius scales the convolution kernel quadratically — blur(10px) is ~4× slower than blur(5px). Keep radii under 20px for 60fps. On mobile, cap at 12px. Use will-change: filter if animating.

2. brightness() — Lighten or Darken Without Opacity

filter: brightness(0.5);    /* 50% darker */
filter: brightness(1);      /* Normal (default) */
filter: brightness(2);      /* 2× brighter */
filter: brightness(0%);     /* Completely black */

What it does: Linear multiplier on each color channel. At 0%, the element becomes pure black. At 100% (1.0), it's unchanged. Above 100%, it brightens linearly — values above 3.0 wash out into white.

Performance: Essentially free. It's a per-channel multiply — the GPU can do this at zero cost alongside compositing.

3. contrast() — Control Dynamic Range

filter: contrast(0.5);     /* Washed out, flat */
filter: contrast(1);       /* Normal */
filter: contrast(2);       /* Punchy, high contrast */
filter: contrast(0%);      /* Uniform gray */

What it does: Adjusts the difference between the lightest and darkest parts. At 0%, the entire element becomes a uniform mid-gray. Below 100%, the image flattens. Above 100%, darks get darker and lights get lighter.

The classic gooey metaball trick: filter: blur(10px) contrast(20) — blur merges shapes, contrast re-sharpens the merged boundary. This is a pure CSS alternative to SVG goo filters.

4. drop-shadow() — The Smarter Box-Shadow

filter: drop-shadow(4px 4px 8px rgba(0,0,0,0.5));
/*                  offset-x offset-y blur-radius color */

What it does: Takes the alpha mask of the element and draws a shadow behind them. Unlike box-shadow, this follows the actual shape — perfect for PNG images, clip-path shapes, and transparent SVGs.

Critical difference: box-shadow follows the CSS box model (border-radius included), while drop-shadow() follows the alpha channel — honoring clip-path, PNG transparency, and irregular shapes. box-shadow supports inset and spread; drop-shadow() does not.

5. grayscale() — Desaturate With Precision

filter: grayscale(0.3);     /* 30% desaturated */
filter: grayscale(1);       /* Fully grayscale */

The "fade to color" pattern: grayscale(1) on default state, animate to grayscale(0) on hover. This is one of the most reliable CSS hover effects — works on every browser, no layout shift, smooth animation.

6. hue-rotate() — Shift the Color Wheel

filter: hue-rotate(90deg);     /* Rotate 90° around the color wheel */
filter: hue-rotate(180deg);    /* Complementary colors */

The single-SVG color palette trick: Ship one blue SVG icon, then use hue-rotate() plus brightness() and saturate() for infinite color variants. This eliminates the need for multiple colored icon assets.

7. invert() — Color Negative

filter: invert(0.5);       /* 50% inverted (mid-gray) */
filter: invert(1);         /* Full color negative */

The dark-mode image trick: invert(1) hue-rotate(180deg) inverts colors but corrects the hue. This works surprisingly well for diagrams, screenshots, and logos.

8. opacity() — The Filter-Based Alternative

Functionally identical to the CSS opacity property, but applied as part of the filter chain. This avoids the stacking context and compositing cost that opacity triggers separately.

9. saturate() — Boost or Mute Color Intensity

filter: saturate(0.5);     /* Muted, pastel */
filter: saturate(2);       /* Vibrant, oversaturated */

10. sepia() — Vintage Photography

filter: sepia(0.5);        /* 50% sepia-toned */
filter: sepia(1);          /* Full sepia */

11. url() — The SVG Filter Escape Hatch

filter: url(#my-custom-filter);
filter: url(filters.svg#displacement);
filter: blur(2px) url(#glow) contrast(1.2);

Applies an SVG <filter> element as part of the CSS filter chain. This unlocks effects CSS filters can't do: displacement maps, lighting, morphology, turbulence, component transfer, and custom convolution matrices.

Chaining Filters: Order Matters

Filters are applied left to right. blur(5px) brightness(0.5) produces a soft dark glow, while brightness(0.5) blur(5px) produces sharp edges with a dark blur — different visual outcomes.

Rule of thumb: For glow effects → blur first. For shadow effects → brightness first. For color effects → grayscale/sepia first. For dark mode images → invert first.

Performance Deep Dive

All CSS filter functions run on the GPU compositor thread — they don't trigger layout or paint. But backdrop-filter is significantly more expensive because the browser must composite everything behind the element first.

Cost hierarchy (cheapest → most expensive): brightness/contrast/grayscale/invert/opacity/saturate/sepia/hue-rotate are essentially free. drop-shadow and small blur are cheap. blur above 15px and complex SVG url() pipelines are expensive.

Animating Filters

@keyframes glowing {
  0%, 100% {
    filter: drop-shadow(0 0 8px rgba(99, 102, 241, 0.6));
  }
  50% {
    filter: drop-shadow(0 0 20px rgba(99, 102, 241, 1))
            drop-shadow(0 0 40px rgba(99, 102, 241, 0.4));
  }
}

Real-World Recipes

Glassmorphism Card

.glass-card {
  background: rgba(255, 255, 255, 0.03);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 16px;
  backdrop-filter: blur(16px) saturate(1.2);
}

Image Color Matrix (Theming)

.icon-brand-primary   { filter: none; }
.icon-brand-secondary { filter: hue-rotate(45deg) saturate(1.3) brightness(0.9); }
.icon-brand-accent    { filter: hue-rotate(320deg) saturate(1.5) brightness(1.1); }

Text Glow (No text-shadow Needed)

.glow-text {
  filter: drop-shadow(0 0 6px currentColor) drop-shadow(0 0 12px currentColor);
}

Browser Support & Fallbacks

All 11 CSS filter functions have been supported since Chrome 53 (2016), Firefox 35 (2015), Safari 9.1 (2016), and Edge 13 (2015). For backdrop-filter, always provide a solid-color fallback: 

.modal {
  background: rgba(15, 23, 42, 0.92);
  @supports (backdrop-filter: blur(12px)) {
    background: rgba(15, 23, 42, 0.7);
    backdrop-filter: blur(12px) saturate(1.5);
  }
}

Key Takeaways

  • Filters are GPU-composited — they don't trigger layout or paint. Use them freely for visual effects.
  • drop-shadow() is not box-shadow — it follows alpha, not the box model. Use it for PNGs and irregular shapes.
  • Order matters — blur() then brightness() ≠ brightness() then blur().
  • backdrop-filter is expensive — provide solid-color fallbacks for mobile.
  • Use will-change: filter before animating to avoid first-frame jank.
  • SVG url() filters unlock displacement maps, lighting, turbulence, and convolution.
  • Chain filters for infinite color variants — one SVG icon + brightness/saturate/hue-rotate = any color.
