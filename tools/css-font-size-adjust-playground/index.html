CSS font-size-adjust Playground

Preserve x-height across font fallbacks — the CSS property that makes fallback fonts look the same size as your primary font. Baseline 2024, zero JavaScript required.

Presets

Font Stacks

font-size-adjust Value

The primary font's x-height is 44.7% of its font-size. The fallback font will be scaled to match this ratio.

Text Properties

Generated CSS
.type-sample {
  font-family: 'Times New Roman', serif, Arial;
  font-size-adjust: 0.447;
  font-size: 1.25rem;
  font-weight: 400;
}

How font-size-adjust works: Every font has an x-height ratio (height of lowercase “x” ÷ font-size). When a fallback font loads, the browser scales it so its x-height matches the primary font’s x-height. This keeps visual rhythm consistent even when fonts fail to load.

Baseline 2024 — supported in all modern browsers: Chrome 127+, Firefox 3+, Safari 16.4+, Edge 127+.
