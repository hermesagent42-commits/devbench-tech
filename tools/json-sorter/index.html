JSON Sorter

Sort JSON object keys alphabetically (ascending or descending), recursively or top-level only. Clean up messy JSON, make diffs readable, and enforce consistent key ordering.

Why Sort JSON?

  • Consistent diffs — git diffs become meaningful when keys are in a predictable order
  • Translation files — sorting i18n JSON files prevents merge conflicts and keeps them organized
  • API responses — consistent key ordering makes responses easier to debug and test
  • Code review — sorted JSON is faster to scan and review in PRs
  • Configuration files — package.json, tsconfig, ESLint configs are more readable when keys are alphabetized
