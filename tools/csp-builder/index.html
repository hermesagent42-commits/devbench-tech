Common Source Values Reference

'self'Same origin as the document.
'none'Block all sources. Most restrictive.
'unsafe-inline'Allow inline scripts/styles. Avoid if possible.
'unsafe-eval'Allow eval() and Function constructor.
'strict-dynamic'Trust scripts loaded by trusted scripts.
'nonce-...'Allow script/style with matching nonce attr.
'sha256-...'Allow inline if it matches this hash.
data:Allow data: URIs (e.g., inline images).
https:Allow any HTTPS source.
blob:Allow blob: URLs (e.g., web workers).
*Allow any source. Very permissive.
wss:Allow secure WebSocket connections.

Tips for a Strong CSP

  • • Start with Report-Only mode to monitor violations without breaking your site.
  • • Avoid 'unsafe-inline' — use nonces or hashes instead for inline scripts/styles.
  • • Set object-src 'none' to block legacy plugin vectors (Flash, Java).
  • • Use frame-ancestors 'self' to prevent clickjacking (replaces X-Frame-Options).
  • • After testing, switch to enforcing mode by unchecking Report-Only.
  • • Test your policy with Google's CSP Evaluator before deploying.
