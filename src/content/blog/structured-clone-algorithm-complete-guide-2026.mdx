## The Problem: JavaScript Doesn't Have Real Deep Copy

Every JavaScript developer has written this bug:

```javascript
const original = { user: { name: 'Alice', prefs: { theme: 'dark' } } };
const copy = { ...original };
copy.user.prefs.theme = 'light';
console.log(original.user.prefs.theme); // 'light' — mutated!
```

Spread operators, `Object.assign()`, and `Array.from()` all do _shallow_ copies. Nested objects share references, so mutations propagate silently. This causes subtle bugs — especially in state management, undo/redo systems, and nested data.

The go-to workaround for years was JSON round-tripping:

```javascript
const deepCopy = JSON.parse(JSON.stringify(original));
```

This works for simple data but has catastrophic limitations:
- **Destroys** `Date` objects (they become ISO strings)
- **Destroys** `RegExp` (becomes `{}`)
- **Silently drops** `undefined`, functions, and `Symbol`
- **Chokes** on circular references with `TypeError: Converting circular structure to JSON`
- **Conflates** `Map`, `Set`, `Blob`, `ArrayBuffer`, and TypedArrays into useless structures

Since 2022, every browser (and Node.js ≥ 17.0) ships the real solution: `structuredClone()`. It implements the **Structured Clone Algorithm** — a deep-level specification (HTML Standard §2.7) originally designed for serializing JavaScript values across realms. It's the same algorithm that powers `postMessage`, `history.pushState()`, `Notification` data, and IndexedDB.

## structuredClone(): The One-Line Deep Copy

```javascript
const original = {
  name: 'Alice',
  created: new Date('2024-01-15'),
  pattern: /hello/i,
  tags: new Set(['admin', 'editor']),
  metadata: new Map([['version', 2], ['active', true]]),
  buffer: new Uint8Array([0, 1, 2, 255]),
};

const clone = structuredClone(original);

// Every type is preserved
console.log(clone.created instanceof Date);              // true
console.log(clone.pattern instanceof RegExp);             // true
console.log(clone.tags instanceof Set);                   // true
console.log(clone.metadata instanceof Map);               // true
console.log(clone.buffer instanceof Uint8Array);          // true

// No shared references
console.log(original.tags === clone.tags);                // false
```

This is the real deep copy JavaScript always needed. But it's not magic — the algorithm supports a specific, well-documented set of types and has strict limits on what can't be cloned.

## What structuredClone() CAN Clone

The structured clone algorithm supports these types natively. Every one produces a genuine, independent copy.

### Built-in objects (preserved by type)

```javascript
structuredClone(new Date('2024-06-10'));       // Date — preserved
structuredClone(/pattern/flags);                // RegExp — preserved
structuredClone(new Map([['key', 'value']]));   // Map — preserved
structuredClone(new Set([1, 2, 3]));            // Set — preserved
structuredClone(new Error('Something went wrong')); // Error — preserved
```

### Indexed collections and typed data

```javascript
structuredClone(new ArrayBuffer(8));            // ArrayBuffer
structuredClone(new Uint8Array([0, 1, 2]));     // TypedArray — all variants
structuredClone(new DataView(new ArrayBuffer(8))); // DataView
structuredClone(new Int32Array([42]));          // Float64Array, etc.
structuredClone(new Blob(['hello'], { type: 'text/plain' })); // Blob
structuredClone(new File(['content'], 'file.txt'));             // File
structuredClone(new ImageData(100, 100));       // ImageData (browser)
```

### Circular references — zero configuration

This is the killer feature over JSON:

```javascript
const obj = { name: 'root' };
obj.self = obj;       // circular reference
obj.children = [
  { parent: obj },    // circular reference through array
];

const clone = structuredClone(obj);
console.log(clone.self === clone);              // true — circularity preserved
console.log(clone.children[0].parent === clone); // true
```

No special handling, no tracking maps, no manual cycle detection. The algorithm handles it natively.

## What structuredClone() CANNOT Clone

The spec explicitly rejects certain types. Calling `structuredClone()` on them throws a `DataCloneError`.

### Functions (all kinds)

```javascript
structuredClone(function() {});    // ❌ DataCloneError
structuredClone(() => {});         // ❌ DataCloneError
structuredClone(async () => {});   // ❌ DataCloneError
structuredClone(class {});         // ❌ DataCloneError
```

Functions capture closures (scope chains) tied to their execution context. No serializable representation.

### DOM nodes

```javascript
structuredClone(document.body);           // ❌ DataCloneError
structuredClone(document.querySelector('div')); // ❌ DataCloneError
```

DOM nodes contain pointers to parent, siblings, event listeners, and layout state.

### Symbols and Symbol-keyed properties

```javascript
structuredClone(Symbol('myKey'));                   // ❌ DataCloneError
structuredClone({ [Symbol('x')]: 'value' });        // ❌ DataCloneError
structuredClone(Symbol.for('shared'));               // ❌ DataCloneError
```

Symbols are guaranteed-unique references — cloning violates their uniqueness contract.

### WeakMap, WeakSet, WeakRef

```javascript
structuredClone(new WeakMap());  // ❌ DataCloneError
structuredClone(new WeakSet());  // ❌ DataCloneError
```

Weak collections don't prevent garbage collection and have no iterators — can't enumerate contents.

### SharedArrayBuffer (without transfer)

```javascript
structuredClone(new SharedArrayBuffer(16));  // ❌ DataCloneError
```

Designed for concurrent access across threads. Use the `transfer` option instead.

### Proxies

```javascript
structuredClone(new Proxy({}, { get: () => 42 })); // ❌ DataCloneError
```

Trap handlers are functions (not clonable), and proxy identity gives behavior meaning.

### Object.prototype and class instances

```javascript
class Custom {
  constructor(name) { this.name = name; }
  greet() { return \`Hello ${this.name}\`; }
}

const instance = new Custom('Alice');
const clone = structuredClone(instance);
console.log(clone instanceof Custom);  // false — prototype chain is lost
console.log(clone.greet);              // undefined — methods are dropped
```

`structuredClone` copies own enumerable properties but ignores the prototype chain. The fix:

```javascript
function cloneWithClass(instance) {
  const data = structuredClone(instance);
  return Object.assign(Object.create(instance.constructor.prototype), data);
}

const properClone = cloneWithClass(new Custom('Alice'));
console.log(properClone instanceof Custom); // true
console.log(properClone.greet());            // 'Hello Alice'
```

## The Transfer Option: Zero-Copy for Move Semantics

`structuredClone` accepts an options object with a `transfer` array. This moves ownership of `ArrayBuffer`-backed objects instead of copying:

```javascript
const buffer = new ArrayBuffer(1024 * 1024 * 100); // 100 MB
const view = new Uint8Array(buffer);
view[0] = 42;

// Transfer — no copy, just pointer handoff
const clone = structuredClone(view, { transfer: [buffer] });

console.log(clone[0]);   // 42 — data was moved
console.log(buffer.byteLength); // 0 — original is detached (zero bytes)
console.log(view.byteLength);   // 0 — view of detached buffer
```

This is critical for large binary data. A 100 MB buffer normally copies byte-for-byte. With transfer, it's O(1) pointer reassignment.

### Transferable objects list

All of these support zero-copy transfer: `ArrayBuffer`, `MessagePort`, `ReadableStream`, `WritableStream`, `TransformStream`, `ImageBitmap`, `OffscreenCanvas`.

## Real-World Patterns

### Pattern 1: Undo/Redo State Snapshots

```javascript
class UndoManager {
  #stack = [];
  #index = -1;
  #maxSize = 50;

  capture(state) {
    this.#stack = this.#stack.slice(0, this.#index + 1);
    this.#stack.push(structuredClone(state));
    this.#index++;
    if (this.#stack.length > this.#maxSize) {
      this.#stack.shift();
      this.#index--;
    }
  }

  undo() {
    if (this.#index > 0) return this.#stack[--this.#index];
    return null;
  }

  redo() {
    if (this.#index < this.#stack.length - 1) return this.#stack[++this.#index];
    return null;
  }
}
```

Without structured clone, modifying state would mutate all snapshots. With it, each snapshot is immutable.

### Pattern 2: Web Worker Communication

```javascript
// main.js
const worker = new Worker('worker.js');

const data = {
  pixels: new Uint8ClampedArray(1920 * 1080 * 4), // ~8 MB pixel data
  metadata: { width: 1920, height: 1080, timestamp: new Date() },
};

worker.postMessage(data, [data.pixels.buffer]);
console.log(data.pixels.byteLength); // 0 — transferred, no longer accessible

// worker.js
self.onmessage = (e) => {
  console.log(e.data.metadata.timestamp instanceof Date); // true
  console.log(e.data.metadata.width);                      // 1920
};
```

Every `postMessage` uses structured clone under the hood. Learning its rules means knowing exactly what survives the trip.

### Pattern 3: IndexedDB — Why Data Disappears

IndexedDB uses structured clone to serialize objects for storage:

```javascript
const item = {
  id: 'abc123',
  created: new Date(),
  tags: new Set(['a', 'b']),
  process() { return 'done'; },    // function — silently dropped
  [Symbol('x')]: 'secret',         // Symbol key — silently dropped
};

await db.put('items', item, 'key1');
const retrieved = await db.get('items', 'key1');

console.log(retrieved.created instanceof Date); // true — Date preserved
console.log(retrieved.tags instanceof Set);     // true — Set preserved
console.log(retrieved.process);                 // undefined — function dropped
console.log(Object.getOwnPropertySymbols(retrieved)); // [] — Symbol dropped
```

This explains almost every "IndexedDB silently losing data" bug.

### Pattern 4: Broadcasting State Across Tabs

```javascript
const channel = new BroadcastChannel('app-state');

channel.postMessage({
  user: { name: 'Alice', prefs: new Map([['theme', 'dark']]) },
  lastUpdated: new Date(),
});

channel.onmessage = (e) => {
  console.log(e.data.user.prefs instanceof Map); // true
  console.log(e.data.lastUpdated instanceof Date); // true
  // Independent copies — safe to mutate
};
```

### Pattern 5: Deep Object Comparison

```javascript
function deepEqual(a, b) {
  if (a === b) return true;
  if (a == null || b == null) return false;
  if (typeof a !== typeof b) return false;

  if (a instanceof Date && b instanceof Date) return a.getTime() === b.getTime();
  if (a instanceof RegExp && b instanceof RegExp) return a.toString() === b.toString();
  if (a instanceof Map && b instanceof Map) {
    if (a.size !== b.size) return false;
    for (const [k, v] of a) if (!deepEqual(v, b.get(k))) return false;
    return true;
  }
  if (a instanceof Set && b instanceof Set) {
    if (a.size !== b.size) return false;
    return [...a].every(val => [...b].some(bVal => deepEqual(val, bVal)));
  }
  if (a instanceof ArrayBuffer && b instanceof ArrayBuffer) {
    if (a.byteLength !== b.byteLength) return false;
    return new Uint8Array(a).every((byte, i) => byte === new Uint8Array(b)[i]);
  }

  if (typeof a === 'object') {
    const keysA = Object.keys(a), keysB = Object.keys(b);
    if (keysA.length !== keysB.length) return false;
    return keysA.every(k => deepEqual(a[k], b[k]));
  }
  return a === b;
}
```

## Performance

Real-world numbers (Chrome 126, M2 Mac):

```javascript
// Small object (~1 KB)
// structuredClone: ~0.01 ms | JSON round-trip: ~0.01 ms

// Medium object (~100 KB) — 10,000 items
// structuredClone: ~0.5 ms | JSON round-trip: ~1.2 ms

// Large object (~10 MB) — typed buffer
// structuredClone: ~12 ms | structuredClone + transfer: ~0.01 ms | JSON: ~150 ms (loses types)
```

For objects under ~1 MB, `structuredClone` is fast enough for every keystroke. For larger data, use transfer.

## structuredClone Is Everywhere

Once you understand the structured clone algorithm, you understand the data contract of half the Web API:

- **`window.postMessage()`** — every cross-origin message
- **`MessagePort.postMessage()`** — every Web Worker communication
- **`BroadcastChannel.postMessage()`** — every cross-tab broadcast
- **`history.pushState()` / `replaceState()`** — every SPA navigation
- **`Notification()` constructor `data` option** — every push notification payload
- **`IndexedDB` reads and writes** — every persistent storage operation
- **`Cache API` (Service Worker)** — every cached response
- **`PaymentRequest` constructor details** — every checkout flow

The same rules apply everywhere: Date survives, RegExp survives, Map/Set survive, Blob/File survive; functions are dropped, Symbol is dropped, DOM nodes are rejected. Learn it once and you're fluent across the entire platform.

## Summary

`structuredClone()` is the deep-copy primitive JavaScript always needed. It handles every structured-clonable type, supports circular references, offers zero-copy transfer for large buffers, and costs zero bytes. It's the same algorithm powering `postMessage`, IndexedDB, and half the web platform — learn it once and you understand the data contract everywhere.

The one thing to remember: **clone what you need to isolate, transfer what you need to move, and never assume class prototypes survive the round trip.**

Replace your `JSON.parse(JSON.stringify(obj))` calls with `structuredClone(obj)` and your code will be faster, handle more types correctly, and never choke on a circular reference again.
