<h2 class="post-h2">Why Date Is Broken</h2>

<p class="post-p">
JavaScript's <code class="inline-code">Date</code> object was copied from Java's <code class="inline-code">java.util.Date</code> in 1995 — and it shows. Every JavaScript developer has been burned by it:
</p>

<pre class="code-block"><code class="language-javascript">// Month is zero-indexed. February is 1. Yes, really.
<p class="post-p">
new Date(2026, 1, 1)  // Feb 1, 2026 — not January.
</p>

<p class="post-p">
// Mutability hell
const d = new Date();
d.setMonth(d.getMonth() + 1);  // Mutates d. Hope nothing else had a reference.
</p>

<p class="post-p">
// Timezone chaos
new Date('2026-01-01')  // UTC midnight or local midnight? It depends on the browser.
</p>

<p class="post-p">
// No distinction between dates without time and full timestamps
// No built-in duration arithmetic
// No plain date/time types
// Parsing is inconsistent across browsers
</code></pre>
</p>

<p class="post-p">
For 30 years, developers have reached for moment.js, dayjs, date-fns, and luxon to paper over these cracks. The Temporal API — now Stage 3 and shipping in all modern browsers — is the permanent fix.
</p>

<h2 class="post-h2">The Temporal Architecture</h2>

<p class="post-p">
Temporal isn't one object — it's a family of purpose-built types:
</p>

<p class="post-p">
| Type | What It Represents | Example |
|------|-------------------|---------|
| <code class="inline-code">Temporal.PlainDate</code> | Calendar date, no time, no timezone | <code class="inline-code">2026-05-27</code> |
| <code class="inline-code">Temporal.PlainTime</code> | Wall-clock time, no date, no timezone | <code class="inline-code">14:30:00.000</code> |
| <code class="inline-code">Temporal.PlainDateTime</code> | Calendar date + wall-clock time | <code class="inline-code">2026-05-27T14:30:00</code> |
| <code class="inline-code">Temporal.PlainYearMonth</code> | A year and month | <code class="inline-code">2026-05</code> |
| <code class="inline-code">Temporal.PlainMonthDay</code> | A month and day, no year | <code class="inline-code">05-27</code> |
| <code class="inline-code">Temporal.ZonedDateTime</code> | Exact absolute time with timezone | <code class="inline-code">2026-05-27T14:30:00-04:00[America/New_York]</code> |
| <code class="inline-code">Temporal.Instant</code> | A single point on the timeline (epoch nanoseconds) | Absolute time, no calendar |
| <code class="inline-code">Temporal.Duration</code> | A difference between two temporal points | <code class="inline-code">P1Y2M3DT4H5M6S</code> |
| <code class="inline-code">Temporal.TimeZone</code> | IANA timezone representation | <code class="inline-code">America/New_York</code> |
| <code class="inline-code">Temporal.Calendar</code> | Calendar system | <code class="inline-code">iso8601</code>, <code class="inline-code">japanese</code>, <code class="inline-code">hebrew</code> |
</p>

<p class="post-p">
The key insight: <strong>all Temporal objects are immutable</strong>. Every method returns a new instance. No more defensive cloning.
</p>

<h2 class="post-h2">Getting Started: The Basics</h2>

<h3 class="post-h3">Creating Temporal Objects</h3>

<pre class="code-block"><code class="language-javascript">// Today's date
<p class="post-p">
const today = Temporal.Now.plainDateISO();
// PlainDate { year: 2026, month: 5, day: 27 }
</p>

<p class="post-p">
// Specific date
const launch = new Temporal.PlainDate(2024, 1, 15);
</p>

<p class="post-p">
// From string
const fromString = Temporal.PlainDate.from('2026-05-27');
</p>

<p class="post-p">
// Current time
const now = Temporal.Now.plainTimeISO();
// PlainTime { hour: 14, minute: 30, second: 0, millisecond: 0, ... }
</p>

<p class="post-p">
// Current zoned datetime (with timezone)
const nycNow = Temporal.Now.zonedDateTimeISO('America/New_York');
// ZonedDateTime with full timezone awareness
</p>

<p class="post-p">
// Unix epoch timestamp
const instant = Temporal.Instant.fromEpochMilliseconds(1716844800000);
</code></pre>
</p>

<h3 class="post-h3">Arithmetic — Finally Sane</h3>

<pre class="code-block"><code class="language-javascript">const start = Temporal.PlainDate.from('2026-05-01');

<p class="post-p">
// Add 2 weeks
const twoWeeksLater = start.add({ weeks: 2 });
// PlainDate { year: 2026, month: 5, day: 15 }
</p>

<p class="post-p">
// Subtract 3 months
const threeMonthsEarlier = start.subtract({ months: 3 });
// PlainDate { year: 2026, month: 2, day: 1 }
</p>

<p class="post-p">
// Arithmetic always returns a new object (immutable!)
console.log(start.year);  // Still 2026 — original unchanged
</p>

<p class="post-p">
// Compare dates
const deadline = Temporal.PlainDate.from('2026-06-01');
console.log(Temporal.PlainDate.compare(start, deadline));  // -1 (start is earlier)
</p>

<p class="post-p">
// Check equality
console.log(start.equals(Temporal.PlainDate.from('2026-05-01')));  // true
</code></pre>
</p>

<h3 class="post-h3">Duration — Calculate Differences</h3>

<pre class="code-block"><code class="language-javascript">const eventDate = Temporal.PlainDateTime.from('2026-07-15T10:00');
<p class="post-p">
const now = Temporal.Now.plainDateTimeISO();
</p>

<p class="post-p">
// Duration between two points
const duration = now.until(eventDate);
console.log(duration.days);     // Number of days
console.log(duration.months);   // Number of months
console.log(duration.weeks);    // Number of weeks
</p>

<p class="post-p">
// Or use since() for reverse direction
const elapsed = eventDate.since(now);
</p>

<p class="post-p">
// Format a countdown
const days = duration.days;
const hours = duration.hours;
const minutes = duration.minutes;
console.log(<code class="inline-code">${days} days, ${hours} hours, ${minutes} minutes until the event</code>);
</p>

<p class="post-p">
// Round to nearest unit
const daysOnly = duration.round('days');
// Or with specific rounding behavior
const hoursOnly = duration.round({ smallestUnit: 'hours', roundingMode: 'ceil' });
</code></pre>
</p>

<h2 class="post-h2">Timezone Handling — Actually Correct</h2>

<p class="post-p">
The biggest win for Temporal is timezone handling. With <code class="inline-code">Date</code>, timezone-aware code was a minefield. Temporal makes it explicit:
</p>

<pre class="code-block"><code class="language-javascript">// A ZonedDateTime knows its timezone and handles DST correctly
<p class="post-p">
const nycMeeting = Temporal.ZonedDateTime.from(
'2026-11-01T09:00[America/New_York]'
);
</p>

<p class="post-p">
const tokyoMeeting = Temporal.ZonedDateTime.from(
'2026-11-01T09:00[Asia/Tokyo]'
);
</p>

<p class="post-p">
// These are 13 hours apart, and Temporal knows it
const diff = nycMeeting.until(tokyoMeeting);
console.log(diff.hours);  // 13
</p>

<p class="post-p">
// Convert between timezones
const nycInTokyo = nycMeeting.withTimeZone('Asia/Tokyo');
console.log(nycInTokyo.toString());
// "2026-11-01T22:00:00+09:00[Asia/Tokyo]"
</p>

<p class="post-p">
// DST transitions are handled correctly
// March 8, 2026 at 2:30 AM Eastern — does this time exist? (Spring forward)
const springForward = Temporal.ZonedDateTime.from(
'2026-03-08T02:30[America/New_York]'
);
// Throws RangeError! 2:30 AM doesn't exist on that day (spring forward)
</p>

<p class="post-p">
// Choose the nearest existing time with disambiguation
const resolved = Temporal.ZonedDateTime.from(
'2026-03-08T02:30[America/New_York]',
{ disambiguation: 'later' }
);
console.log(resolved.toString());
// "2026-03-08T03:00:00-04:00[America/New_York]"
</code></pre>
</p>

<h2 class="post-h2">Real-World Patterns</h2>

<h3 class="post-h3">1. Countdown Timer</h3>

<pre class="code-block"><code class="language-javascript">function getCountdown(target: Temporal.PlainDateTime) {
<p class="post-p">
const now = Temporal.Now.plainDateTimeISO();
const remaining = now.until(target, { largestUnit: 'days' });
</p>

<p class="post-p">
return {
days: remaining.days,
hours: remaining.hours,
minutes: remaining.minutes,
seconds: remaining.seconds,
total: remaining.total('seconds'),
isPast: Temporal.PlainDateTime.compare(target, now) &amp;lt; 0,
};
}
</p>

<p class="post-p">
const launchDate = Temporal.PlainDateTime.from('2026-12-25T00:00');
const countdown = getCountdown(launchDate);
console.log(<code class="inline-code">Launch in ${countdown.days} days!</code>);
</code></pre>
</p>

<h3 class="post-h3">2. Age Calculator</h3>

<pre class="code-block"><code class="language-javascript">function calculateAge(birthDate: Temporal.PlainDate) {
<p class="post-p">
const today = Temporal.Now.plainDateISO();
const age = birthDate.until(today, { largestUnit: 'years' });
</p>

<p class="post-p">
return {
years: age.years,
months: age.months,
days: age.days,
nextBirthday: birthDate.with({ year: today.year }).add(
Temporal.PlainDate.compare(
birthDate.with({ year: today.year }), today
) &amp;lt; 0 ? { years: 1 } : { years: 0 }
),
};
}
</p>

<p class="post-p">
const birth = Temporal.PlainDate.from('1990-05-15');
const age = calculateAge(birth);
console.log(<code class="inline-code">Age: ${age.years} years, ${age.months} months</code>);
</code></pre>
</p>

<h3 class="post-h3">3. Meeting Scheduler Across Timezones</h3>

<pre class="code-block"><code class="language-javascript">function findMeetingTime(
<p class="post-p">
participants: { name: string; timezone: string }[],
duration: Temporal.Duration,
windowStart: Temporal.PlainTime,
windowEnd: Temporal.PlainTime,
date: Temporal.PlainDate,
) {
const slots: Temporal.ZonedDateTime[] = [];
</p>

<p class="post-p">
let cursor = date.toZonedDateTime({
timeZone: 'UTC',
plainTime: Temporal.PlainTime.from('00:00'),
});
</p>

<p class="post-p">
const dayEnd = cursor.add({ days: 1 });
</p>

<p class="post-p">
while (Temporal.ZonedDateTime.compare(cursor, dayEnd) &amp;lt; 0) {
const cursorLocal = cursor
</p>

<p class="post-p">
const works = participants.every((p) =&amp;gt; {
const local = cursorLocal.withTimeZone(p.timezone);
const localTime = local.toPlainTime();
return (
Temporal.PlainTime.compare(localTime, windowStart) &amp;gt;= 0 &amp;amp;&amp;amp;
Temporal.PlainTime.compare(localTime, windowEnd) &amp;lt; 0
);
});
</p>

<p class="post-p">
if (works) {
slots.push(cursorLocal);
}
</p>

<p class="post-p">
cursor = cursor.add({ minutes: 30 });
}
</p>

<p class="post-p">
return slots;
}
</p>

<p class="post-p">
const team = [
{ name: 'Alice', timezone: 'America/New_York' },
{ name: 'Bob', timezone: 'Europe/London' },
{ name: 'Charlie', timezone: 'Asia/Tokyo' },
];
</p>

<p class="post-p">
const meetingSlots = findMeetingTime(
team,
Temporal.Duration.from({ hours: 1 }),
Temporal.PlainTime.from('09:00'),
Temporal.PlainTime.from('17:00'),
Temporal.Now.plainDateISO(),
);
</p>

<p class="post-p">
console.log(<code class="inline-code">Found ${meetingSlots.length} possible meeting slots</code>);
</code></pre>
</p>

<h3 class="post-h3">4. Recurring Events</h3>

<pre class="code-block"><code class="language-javascript">function getNextOccurrences(
<p class="post-p">
start: Temporal.PlainDate,
interval: Temporal.Duration,
count: number,
) {
const dates: Temporal.PlainDate[] = [];
let cursor = start;
</p>

<p class="post-p">
for (let i = 0; i &amp;lt; count; i++) {
dates.push(cursor);
cursor = cursor.add(interval);
}
</p>

<p class="post-p">
return dates;
}
</p>

<p class="post-p">
// Biweekly Monday standup
const firstStandup = Temporal.PlainDate.from('2026-06-01');
const standups = getNextOccurrences(
firstStandup,
Temporal.Duration.from({ weeks: 2 }),
12,
);
</p>

<p class="post-p">
standups.forEach((d, i) =&amp;gt; {
console.log(<code class="inline-code">Standup #${i + 1}: ${d.toLocaleString('en-US', { weekday: 'long', month: 'long', day: 'numeric' })}</code>);
});
</code></pre>
</p>

<h3 class="post-h3">5. Business Days Calculator</h3>

<pre class="code-block"><code class="language-javascript">function addBusinessDays(start: Temporal.PlainDate, days: number): Temporal.PlainDate {
<p class="post-p">
let cursor = start;
let added = 0;
const direction = days &amp;gt;= 0 ? 1 : -1;
</p>

<p class="post-p">
while (added &amp;lt; Math.abs(days)) {
cursor = cursor.add({ days: direction });
const dayOfWeek = cursor.dayOfWeek;
if (dayOfWeek !== 6 &amp;amp;&amp;amp; dayOfWeek !== 7) {
added++;
}
}
</p>

<p class="post-p">
return cursor;
}
</p>

<p class="post-p">
const orderDate = Temporal.PlainDate.from('2026-05-22'); // Friday
const delivery = addBusinessDays(orderDate, 3);
console.log(delivery.toString()); // 2026-05-27 (Wed) — skips Sat/Sun
</code></pre>
</p>

<h2 class="post-h2">Comparison with Date and Popular Libraries</h2>

<p class="post-p">
| Feature | <code class="inline-code">Date</code> | <code class="inline-code">Temporal</code> |
|---------|--------|------------|
| Immutability | ❌ Mutable | ✅ Immutable |
| Timezone handling | UTC or local only | Full IANA timezone support |
| Nanosecond precision | ❌ Milliseconds only | ✅ Nanoseconds |
| Plain date (no time) | ❌ | ✅ <code class="inline-code">PlainDate</code> |
| Duration arithmetic | ❌ Manual math | ✅ <code class="inline-code">Duration</code> with rounding |
| DST safety | ❌ Silent errors | ✅ Explicit disambiguation |
| String parsing | Inconsistent | ✅ Strict ISO 8601 |
| Month indexing | 0-11 (insane) | 1-12 (sane) |
</p>

<p class="post-p">
<strong>When to still use libraries:</strong>
</p>
<ul class="post-ul"><li class="post-li"><strong>dayjs/date-fns</strong>: If you're in a legacy codebase and can't polyfill Temporal</li>
<li class="post-li"><strong>luxon</strong>: If you need advanced calendar systems beyond ISO 8601</li>
<li class="post-li"><strong>moment.js</strong>: Never. It's deprecated. Even the maintainers say so.</li>
</ul>
<h2 class="post-h2">Migration Guide</h2>

<h3 class="post-h3">From <code class="inline-code">new Date()</code> to Temporal</h3>

<pre class="code-block"><code class="language-javascript">// Before

const tomorrow = new Date(now);
tomorrow.setDate(tomorrow.getDate() + 1);
</p>

<p class="post-p">
// After
const now = Temporal.Now.plainDateISO();
const tomorrow = now.add({ days: 1 });
</code></pre>
</p>

<h3 class="post-h3">From dayjs</h3>

<pre class="code-block"><code class="language-javascript">// dayjs
<p class="post-p">

const end = dayjs('2026-06-01');

</p>

<p class="post-p">

const start = Temporal.PlainDate.from('2026-05-01');
const end = Temporal.PlainDate.from('2026-06-01');
const diff = start.until(end).days; // 31
</code></pre>
</p>

<h3 class="post-h3">From date-fns</h3>

<pre class="code-block"><code class="language-javascript">// date-fns

<h2 class="post-h2">Common Pitfalls</h2>

<h3 class="post-h3">1. Mixing Types</h3>

<pre class="code-block"><code class="language-javascript">// ❌ Can't add a Duration to a PlainDate without time context
<p class="post-p">
const date = Temporal.PlainDate.from('2026-05-27');
// date.add(Temporal.Duration.from({ hours: 5 })) // Error!
</p>

<p class="post-p">
// ✅ Use PlainDateTime when you need time
const dateTime = Temporal.PlainDateTime.from('2026-05-27T09:00');
dateTime.add(Temporal.Duration.from({ hours: 5 })); // Works
</code></pre>
</p>

<h3 class="post-h3">2. Timezone vs Offset</h3>

<pre class="code-block"><code class="language-javascript">// ❌ Using offset instead of IANA timezone
<p class="post-p">
// Temporal.ZonedDateTime.from('2026-05-27T14:00:00-04:00') // May not handle DST
</p>

<p class="post-p">
// ✅ Always use IANA timezone names
const zoned = Temporal.ZonedDateTime.from('2026-05-27T14:00:00[America/New_York]');
</code></pre>
</p>

<h3 class="post-h3">3. Balance vs Round</h3>

<pre class="code-block"><code class="language-javascript">const duration = Temporal.Duration.from({ hours: 25, minutes: 90 });

<p class="post-p">
// balance() normalizes units but may create more granular ones
duration.round({ largestUnit: 'days' });
// { days: 1, hours: 2, minutes: 30 }
</p>

<p class="post-p">
// If you just want total hours:
duration.total('hours'); // 26.5
</code></pre>
</p>
