How to Use

  1. Choose a pattern type and tweak the controls until you like how it looks.
  2. Copy the CSS output and paste into your stylesheet — the pattern is embedded as a data:image/svg+xml URI.
  3. No external images, no additional HTTP requests. The entire pattern weighs just a few hundred bytes.
  4. Use as a background-image on any element — hero sections, cards, footers, or even ::before pseudo-elements.
  5. All patterns repeat seamlessly (tile) in both directions. Scale adjusts the pattern density without breaking tiling.

Common Use Cases

Card Backgrounds

Light geometric pattern on cards to break up flat color without adding weight.

Dark Mode Depth

Dark backgrounds benefit from subtle patterns to avoid looking flat and empty.

Print-Style Layouts

Crosshatch or fabric patterns for editorial, magazine-style designs.
