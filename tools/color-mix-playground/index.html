The color-mix() function is supported in all modern browsers (Baseline 2025). The color space determines HOW the two colors blend — oklch gives the most perceptually pleasing results.

💡 Why color-mix()?

  • • No JavaScript needed — CSS handles interpolation
  • • Respects color space — mix in perceptually uniform spaces like Oklch
  • • Works with custom properties — var(‑‑brand)
  • • Animatable — transition the percentage for smooth effects

🎨 When to use each space

  • • oklch / oklab — best perceptual results, modern default
  • • srgb — legacy default, matches most screens
  • • lch / lab — good gradients, wide browser support
  • • display-p3 — HDR displays, wider color gamut
