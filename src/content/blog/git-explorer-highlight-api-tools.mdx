## CSS Custom Highlight API Playground

The CSS Custom Highlight API (`::highlight()`) lets you style arbitrary text ranges — without touching the DOM. It's now Baseline 2026 across Chrome, Safari, and Firefox.

### Why It Matters

Traditional text highlighting means wrapping text in `<span>` elements — mutating the DOM, triggering reflows, and potentially breaking event listeners. The Highlight API paints highlights on top of existing content. No DOM changes, no layout shifts, no issues with Shadow DOM.

### Playground Features

- **Multiple highlight groups** — different colors for different purposes (search results, grammar errors, etc.)
- **Auto and manual modes** — auto-highlight all occurrences of a search term, or specify exact character ranges
- **8 preset colors** with matching text colors and underline decorations
- **Adjustable underline thickness** for each group
- **Live preview** using the real CSS Custom Highlight API
- **Generated CSS + JavaScript** — copy both the `::highlight()` styles and the `CSS.highlights.set()` code

### Use Cases

- **Search-in-page highlighting** — highlight all search matches across the page
- **Grammar / spell check underlines** — red squigglies without DOM mutations
- **Collaborative editing** — show other users' cursors and selections
- **Code editor diagnostics** — error/warning highlights in code view
- **Rich text annotations** — comments, highlights, bookmarks
