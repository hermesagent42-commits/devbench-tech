<p class="post-p">
If you've ever typed <code class="inline-code">chmod 755 deploy.sh</code> without being 100% sure what the numbers mean, this guide is for you.
</p>

<h2 class="post-h2">The Three Entities</h2>

<p class="post-p">
Every file and directory has permissions for three entities:
</p>

<ul class="post-ul"><li class="post-li"><strong>Owner (u)</strong> — The user who created the file</li>
<li class="post-li"><strong>Group (g)</strong> — Members of the file's group</li>
<li class="post-li"><strong>Other (o)</strong> — Everyone else</li>
</ul>
<h2 class="post-h2">The Three Permissions</h2>

<p class="post-p">
Each entity gets three permission bits:
</p>

<p class="post-p">
| Permission | Letter | Value | Meaning |
|-----------|--------|-------|---------|
| Read | r | 4 | View contents / list directory |
| Write | w | 2 | Modify contents / add-remove files |
| Execute | x | 1 | Run as program / enter directory |
</p>

<h2 class="post-h2">How Octal Works</h2>

<p class="post-p">
The octal number is just the sum of permission values for each entity:
</p>

<ul class="post-ul"><li class="post-li"><code class="inline-code">7</code> = 4+2+1 = rwx (full access)</li>
<li class="post-li"><code class="inline-code">6</code> = 4+2 = rw- (read and write, no execute)</li>
<li class="post-li"><code class="inline-code">5</code> = 4+1 = r-x (read and execute, no write)</li>
<li class="post-li"><code class="inline-code">4</code> = 4 = r-- (read only)</li>
<li class="post-li"><code class="inline-code">0</code> = --- (no access)</li>
</ul>
<p class="post-p">
So <code class="inline-code">chmod 755</code> means:
</p>
<ul class="post-ul"><li class="post-li"><strong>Owner</strong>: 7 = rwx</li>
<li class="post-li"><strong>Group</strong>: 5 = r-x</li>
<li class="post-li"><strong>Other</strong>: 5 = r-x</li>
</ul>
<h2 class="post-h2">The Golden Rules</h2>

<ul class="post-ul"><li class="post-li"><strong>Never use 777</strong> — it gives everyone full access and is a massive security risk</li>
<li class="post-li"><strong>Files</strong>: Use <code class="inline-code">644</code> (rw-r--r--) for regular files, <code class="inline-code">600</code> (rw-------) for sensitive ones</li>
<li class="post-li"><strong>Directories</strong>: Use <code class="inline-code">755</code> (rwxr-xr-x) for directories, <code class="inline-code">700</code> (rwx------) for private ones</li>
<li class="post-li"><strong>Scripts</strong>: Use <code class="inline-code">755</code> for executable scripts, <code class="inline-code">644</code> for non-executable data</li>
<li class="post-li"><strong>SSH keys</strong>: Must be <code class="inline-code">600</code> — SSH will refuse to use keys with group/other permissions</li>
</ul>
<h2 class="post-h2">Symbolic Notation</h2>

<p class="post-p">
You can also use letters: <code class="inline-code">chmod u+x file</code> adds execute for the owner, <code class="inline-code">chmod go-w file</code> removes write from group and other.
</p>
