About the ASCII Table

ASCII (American Standard Code for Information Interchange) maps 128 characters \u2014 letters, digits, punctuation, and control codes \u2014 to numbers 0\u2013127. Every modern encoding (UTF-8, ISO-8859) is backward-compatible with ASCII.
