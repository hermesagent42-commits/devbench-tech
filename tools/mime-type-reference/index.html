MIME Type Reference

Complete reference of 70+ MIME types organized by category. Search, filter, and copy content-type strings for HTTP headers, form uploads, and API responses.

Text

(12 types)
text/calendar.ics

iCalendar

iCalendar format — calendar events, to-do items, meeting requests.

text/css.css

CSS

Cascading Style Sheets — styles for HTML documents.

text/csv.csv

CSV

Comma-Separated Values — tabular data as plain text.

text/html.html

HTML

HyperText Markup Language — the standard web page format.

text/javascript.js

JavaScript

JavaScript source code (deprecated; use application/javascript).

text/markdown.md

Markdown

Markdown formatted text — used in READMEs, docs, forums.

text/plain.txt

Plain Text

Unformatted text. The simplest and most universal content type.

text/rtf.rtf

Rich Text Format

Rich Text Format — formatted text with basic styling.

text/tab-separated-values.tsv

TSV

Tab-Separated Values — alternative to CSV with tab delimiter.

text/vcard.vcf

vCard

Electronic business card — contact information.

text/xml.xml

XML

Extensible Markup Language — structured data interchange.

text/yaml.yaml

YAML

YAML Ain't Markup Language — human-readable config/data.

Application

(24 types)
application/graphql.graphql

GraphQL

GraphQL query or schema document.

application/gzip.gz

GZIP

GNU Zip compressed file — single-file compression.

application/javascript.js

JavaScript

JavaScript source code (preferred over text/javascript).

application/json.json

JSON

JavaScript Object Notation — the universal API data format.

application/ld+json.jsonld

JSON-LD

JSON for Linked Data — structured data for SEO (Schema.org).

application/octet-stream

Binary Data

Generic binary data — catch-all for unknown formats. Triggers download in browsers.

application/pdf.pdf

PDF

Portable Document Format — universal document sharing.

application/problem+json.json

Problem JSON

RFC 7807 Problem Details — standard API error responses.

application/rtf.rtf

Rich Text Format

Rich Text Format (application variant).

application/typescript.ts

TypeScript

TypeScript source code — typed superset of JavaScript.

application/vnd.api+json.json

JSON:API

JSON:API — a specification for building APIs in JSON.

application/wasm.wasm

WebAssembly

WebAssembly binary — low-level bytecode for browsers.

application/x-7z-compressed.7z

7-Zip

7-Zip compressed archive — high compression ratio.

application/x-bzip2.bz2

Bzip2

Bzip2 compressed file — better compression than gzip.

application/x-httpd-php.php

PHP

PHP source code — server-side scripting.

application/x-ndjson.ndjson

NDJSON

Newline Delimited JSON — one JSON object per line. Used for streaming.

application/x-python-code.py

Python

Python source code.

application/x-rar-compressed.rar

RAR Archive

RAR compressed archive — proprietary archive format.

application/x-sh.sh

Shell Script

Unix shell script — bash, sh, zsh.

application/x-tar.tar

TAR Archive

Tape Archive — commonly used with gzip (.tar.gz) or bzip2.

application/x-www-form-urlencoded

URL-Encoded Form

Default HTML form encoding. key=value&key2=value2 format in the request body.

application/x-yaml.yaml

YAML

YAML data (application variant).

application/xml.xml

XML

XML data (preferred over text/xml for data interchange).

application/zip.zip

ZIP Archive

ZIP compressed archive — the most common archive format.

Image

(11 types)
image/avif.avif

AVIF

AVIF — next-gen format based on AV1. Best compression, HDR support.

image/bmp.bmp

BMP

Windows Bitmap — uncompressed raster image.

image/gif.gif

GIF

GIF image — animation support, limited to 256 colors.

image/heic.heic

HEIC

High Efficiency Image Format — Apple's photo format.

image/jpeg.jpg

JPEG

JPEG image — lossy compression, best for photos.

image/jxl.jxl

JPEG XL

JPEG XL — next-gen format. Lossless JPEG recompression, HDR, animation.

image/png.png

PNG

PNG image — lossless compression, supports transparency.

image/svg+xml.svg

SVG

Scalable Vector Graphics — resolution-independent vector images.

image/tiff.tiff

TIFF

Tagged Image File Format — high quality, used in print/scanning.

image/webp.webp

WebP

WebP — Google's modern format. Lossy/lossless, transparency, animation.

image/x-icon.ico

Icon

Windows icon file — used for favicons.

Audio

(8 types)
audio/aac.aac

AAC

Advanced Audio Coding — successor to MP3, better quality at same bitrate.

audio/flac.flac

FLAC

Free Lossless Audio Codec — lossless compression for audiophiles.

audio/midi.mid

MIDI

Musical Instrument Digital Interface — not audio, but performance data.

audio/mp4.m4a

AAC/MP4 Audio

Audio in MP4 container — typically AAC encoding, Apple's preferred format.

audio/mpeg.mp3

MP3

MPEG Audio Layer III — the most popular audio format.

audio/ogg.ogg

OGG Audio

OGG container with Vorbis or Opus codec — open format.

audio/wav.wav

WAV

Waveform Audio — uncompressed PCM audio, CD quality.

audio/webm.weba

WebM Audio

WebM container with Opus or Vorbis — open web audio format.

Video

(7 types)
video/MP2T.ts

MPEG-TS

MPEG Transport Stream — used for live streaming and broadcast.

video/mp4.mp4

MP4 Video

MPEG-4 video — the most widely supported video format. Usually H.264 + AAC.

video/ogg.ogv

OGG Video

OGG video container — open format, Theora codec.

video/quicktime.mov

QuickTime

Apple QuickTime movie — legacy format.

video/webm.webm

WebM Video

WebM video — open format, VP8/VP9 codec, royalty-free.

video/x-matroska.mkv

Matroska

Matroska multimedia container — flexible, open standard.

video/x-msvideo.avi

AVI

Audio Video Interleave — Microsoft container format.

Font

(5 types)
font/collection.ttc

Font Collection

TrueType/OpenType Collection — multiple fonts in one file.

font/otf.otf

OpenType

OpenType Font — PostScript outlines, advanced typography features.

font/ttf.ttf

TrueType

TrueType Font — the original scalable font format.

font/woff.woff

WOFF

Web Open Font Format — compressed, with metadata.

font/woff2.woff2

WOFF2

WOFF 2.0 — 30% better compression. The web font standard.

Multipart

(5 types)
multipart/alternative

Alternative

Same content in multiple formats — used for emails (text + HTML).

multipart/byteranges

Byte Ranges

HTTP 206 Partial Content — multiple byte ranges in one response.

multipart/form-data

Form Data

HTML form submission with file uploads. Each field is a separate part.

multipart/mixed

Mixed

Multiple unrelated parts — email with attachments.

multipart/related

Related

Related parts — HTML email with inline images.
