Cron Syntax Quick Reference

SymbolMeaningExample
*Any value (wildcard)* * * * * → every minute
,Value list separator0,15,30,45 → at 0, 15, 30, 45
-Range of values9-17 → 9 through 17
/Step values*/15 → every 15 (0, 15, 30, 45)
LLast (not standard)Not supported in standard cron
?No specific valueNot supported in standard cron
#Nth weekdayNot supported in standard cron
WNearest weekdayNot supported in standard cron

DevBench uses the standard Unix cron format (5 fields). Quartz-style extended syntax (L, ?, #, W) is not supported here.
