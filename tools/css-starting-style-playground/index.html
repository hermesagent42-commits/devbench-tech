How @starting-style Works

@starting-style is a CSS at-rule that defines the initial state of an element before it first renders in the DOM.

When the element appears (e.g., a popover opens, a dialog shows, or an element is inserted via JavaScript), the browser applies the @starting-style values first, then immediately transitions to the element's computed final state.

This means you can create entry animations with zero JavaScript — just define the starting state and let CSS transitions handle the rest.

Baseline 2026: @starting-style is newly available across all major browsers. It works with popovers, dialogs, and any element that transitions from not-rendered to rendered.
