About shape-outside

shape-outside defines a shape around which adjacent inline content wraps. It only works on floated elements. Combined with clip-path, you can create complex text-wrapping effects — magazine-style layouts, creative pull quotes, and organic text flows. Browser support: all modern browsers (96%+).
