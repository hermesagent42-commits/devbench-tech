CSS Text Decoration Playground

Visually design text decorations — underline, overline, line-through with solid, double, dotted, dashed, and wavy styles. Control color, thickness, offset, and skip-ink. Live preview, longhand + shorthand CSS output.

PRESETS:

Controls whether underlines skip around glyph descenders (the tails on g, j, p, q, y).

Text Decoration Properties Reference

text-decoration-line

underline, overline, line-through, or combinations.

text-decoration-style

solid, double, dotted, dashed, wavy

text-decoration-color

Any CSS color value. Different from color — the line can have a different color than the text.

text-decoration-thickness

auto, from-font, or explicit px / em values.

text-underline-offset

Distance between text baseline and the underline. Can use negative values to draw above descenders.

text-decoration-skip-ink

auto skips glyph descenders; none draws through all characters.
